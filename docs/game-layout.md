# Cashfire game layout

Apply Incentive Games Design System 1.0.0 and Game Layout Studio 1.1.0. Existing supplied header/control references are retained in `incentive-games/reference/`. The full skill child bundle and attachment script were unavailable; existing official studio art and reusable shell are preserved.

The fixed viewport contains the approved navy header, flexible game region, centred PLAY/stake controller when idle or settled, and bet/last-return footer. No page scrolling. Betting controls unmount for starting, playing and paused phases, as explicitly requested; discreet pause, mute and cinematic access remain available. Stake selection uses the existing internally scrolling three-column overlay.

The game region reserves its right side for the complete eleven-tier paytable. Amber YOU and outlined NEXT states communicate progress without relying on colour. Current conditional total return, next-kill total return and 1,000× maximum are visible. A compact five-outcome demo note is retained. Short landscape permits internal table scrolling; ordinary phone and desktop layouts are intended to display all rows. Header/footer geometry and primary-action centring remain unchanged.

Combat, title art, countdown, objective, pause and results use the remaining left region. The original video remains intact. Four clock-driven tactical simulations animate enemies and deaths against existing photographic plates, with action coordinates kept clear of the paytable. All poses follow the accepted round clock; pause does not advance an independent CSS animation. Elimination result and returned zero are explicit; higher-win amounts derive from the unchanged payout table.

Ready: selected next stake, logo, full table. Accepted: one fixed randomly selected outcome and one debit. Active/paused: hidden betting controls, pinned accepted stake, live current/next tiers. Settled: actual death/extraction, actual total return and net result; controls restored. Media errors retain refund/settlement guards and a reachable reload path. See `cashfire-update.md` for fixture identities and evidence limits.
